P7M Extractor

Il documento originale dai file firmati .p7m, in un clic.

I file .p7m (firma digitale CAdES) avvolgono contratti, disegni, allegati PEC e fatture elettroniche in una busta PKCS#7. P7M Extractor la apre e salva il documento originale, identico byte per byte, accanto al file firmato. Trascina file o intere cartelle, oppure fai doppio clic su un .p7m.

Scarica per Windows Installa su Linux (Flatpak) Linux portable Sorgente su GitHub
  • Gratuito e open source (licenza MIT), nessuna dipendenza da installare
  • Estrazione in serie con avanzamento per ogni file, firme annidate risolte in un passaggio
  • Contenitori binari, base64 e PEM, incluso lo streaming BER dei software di firma italiani
  • Interfaccia in italiano e inglese, tema chiaro e scuro

Lo strumento estrae il contenuto firmato: non verifica certificati né il valore legale della firma. Per una verifica con valore legale usa un servizio qualificato (GoSign, ArubaSign, i verificatori accreditati AgID).

English

P7M Extractor unwraps CAdES .p7m digitally signed files and saves the original document, byte for byte, next to the signed one. Drag & drop files or folders, or double-click a .p7m. Free and open source (MIT), for Windows and Linux.
